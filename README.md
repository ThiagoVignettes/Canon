# Canon — Historia de una marca

Sitio web sobre la historia de Canon, hecho como trabajo práctico de la materia
**Introducción a la Programación Web** (UAI).

- **Autor:** Thiago Vignettes
- **Sitio publicado:** https://thiagovignettes.github.io/Canon/

## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio, con contador de visitas |
| `HTML/historia.html` | Línea de tiempo desplegable |
| `HTML/camaras.html` | Tabla de cámaras con filtro por tipo |
| `HTML/objetivos.html` | Monturas FD, EF y RF y objetivos conocidos |
| `HTML/tecnologia.html` | Tecnologías de Canon |
| `HTML/galeria.html` | Fotos con visor, gráficos SVG y video |
| `HTML/glosario.html` | Términos de fotografía |
| `HTML/preguntas-frecuentes.html` | Preguntas frecuentes |
| `HTML/club.html` | Formulario del club de fotografía |
| `HTML/acerca.html` | Autor, tecnologías y fuentes |

## Carpetas

- `CSS/` — `estilos.css` (código fuente, con comentarios) y `estilos.min.css` (versión minificada que usan las páginas).
- `JS/` — un archivo por página, más `comun.js` con el modo claro/oscuro.
- `img/` — fotos optimizadas (menos de 200 KB) y el favicon.

## Tecnologías

HTML, CSS (Flexbox, Grid, media queries), JavaScript (DOM, eventos con
`addEventListener`, funciones flecha) y `localStorage`. No usa librerías externas,
solo las fuentes Montserrat y Open Sans de Google Fonts.

## Cómo verlo en la compu

Abrir la carpeta en Visual Studio Code y usar Live Server sobre `index.html`.

> Si se cambia `estilos.css`, hay que volver a minificarlo en `estilos.min.css`.
